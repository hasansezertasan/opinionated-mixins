# Roadmap

This document outlines the future plans and goals for the opinionated-mixins project.

## Short-term Goals

### 1. Enhance Test Coverage

- Write comprehensive unit and integration tests for each mixin and framework.
- Ensure all edge cases are covered.
- Set up continuous integration to run tests automatically.

### 2. Add New Mixins

- Implement additional mixins such as:
  - `TimestampMixin`: For adding created_at and updated_at fields.
  - `AuditMixin`: For tracking who created and modified records.
  - `SoftDeleteMixin`: For soft deletion functionality.
  - `UUIDMixin`: For using UUID as primary keys.

### 3. Improve Documentation

- Create detailed usage examples for each mixin.
- Document edge cases and framework-specific considerations.
- Set up automatic API documentation using Sphinx or MkDocs.

### 4. Framework Support

- Address inheritance issues in frameworks like ODMantic.
- Add support for additional frameworks (e.g., Django ORM, Marshmallow).

### 5. Package and Distribution

- Automate PyPI releases using GitHub Actions.
- Define optional dependencies in pyproject.toml.

## Long-term Goals

### 1. Community Engagement

- Encourage community contributions.
- Organize regular community meetings or discussions.

### 2. Advanced Features

- Add support for more complex data types and relationships.
- Implement advanced validation and transformation features.

### 3. Integration Examples

- Create more comprehensive example projects.
- Showcase integration with popular web frameworks and tools.

## How to Contribute

If you're interested in contributing to this roadmap, please check out our [CONTRIBUTING.md](CONTRIBUTING.md) file for guidelines on how to get started.
